# Close Project

**Harvest first, then archive.** A project archived without harvesting buries everything reusable it produced.

## 1. Confirm the ending

- **Completed:** the outcome was achieved.
- **Abandoned:** deliberately stopped.
- **Transformed:** it turned out to be an ongoing responsibility. Propose converting it to an Area instead of archiving it.

## 2. Retrospective

Append to the project note (or `Retrospective.md` if long): outcome versus intent, what worked, what didn't, reusable output, loose ends. Honest and short.

## 3. Harvest

Before anything moves, identify what outlives the project: reusable material for an Area or Resource, ongoing responsibilities for an Area, reference knowledge for a Resource, and people worth remembering for `02_Areas/People/`. **Propose the harvest as a list** before moving anything.

## 4. Archive

- Write the manifest to `06_Meta/Logs/` first.
- Move the folder to `04_Archive/Projects/<Project Name>/` (create `Projects/` with the first one).
- Set `status: done` or `dropped`, and `updated` to today.
- Update any Area that listed it under `## Current Projects`.
- Leave inbound wikilinks alone; Obsidian resolves them by name.

## 5. Report

What was harvested and where, what was archived.

## Rules

- Never delete. Archiving is the floor.
- Never archive without harvesting. Offer a two-minute version rather than skipping it.
